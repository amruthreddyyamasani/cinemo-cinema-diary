# Cinemo user flow

## Entry to discovery

A visitor lands on the full-screen cinematic entry. The video is muted and decorative; the headline and primary action remain available if playback fails. Scrolling through the pinned opening maps to the screen push. When the bridge is revealed, the visitor can enter directly, or continue normal scrolling into the product. On mobile and reduced-motion settings, the visitor receives the poster and bridge without the precise camera push.

## First useful action

The visitor searches by title, director, or genre, or selects a poster from the cinematic discovery reel. A film opens in the detail view with its source-labelled metadata. The visitor can add it to the watchlist, mark it watched, favourite it, or add a half-star rating after watching. No preference setup blocks exploration.

## Returning user

A local session restores the diary, theme, watchlist, and quiz state on the same device. The home view surfaces recent watched films and a recommendation whose explanation is based on the actual diary, or clearly says that it is a cold-start suggestion.

## Knowledge assessment

The Knowledge destination presents five verified questions. The user selects an answer, reads the explanation, and submits. The result is a percentage of correct answers, with a transparent methodology note. CountUp is used only on the final real score.

## Recovery

Missing posters receive an image failure treatment. Empty shelves explain the next action. Search with no results offers a shorter query suggestion. Video failure falls back to the poster and never blocks discovery. Reduced motion disables the camera push and retains the product bridge.

## Current completion flow

Discover → open detail → mark watched/watchlist/favourite → rate from 0.5 to 5 → write or delete a private note → revisit the filtered and sorted shelf. Home recommendations use saved watched genres, exclude watched and dismissed films, and offer a wider-angle escape hatch. Knowledge rounds shuffle question order and share only the score text, never account data.
